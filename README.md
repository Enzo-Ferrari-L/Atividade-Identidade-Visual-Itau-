# Atividade-Identidade-Visual-Itaú-


Este projeto foi desenvolvido no **Figma** com o objetivo de criar e organizar uma base visual inspirada na identidade do **Itaú**, reunindo elementos essenciais para a construção de interfaces.

## Elementos desenvolvidos

* **Logo:** representação visual da marca.
* **Cores:** definição das cores primárias, secundárias, tons claros e escuros, além de cores de sucesso e alerta.
* **Tipografia:** utilização da fonte **Poppins** em diferentes pesos.
* **Font Scale:** definição dos tamanhos de texto para títulos, subtítulos e parágrafos.
* **Contraste:** exemplos de combinações entre texto e fundos para garantir boa leitura.

## Ferramenta utilizada

* **Figma** — criação e organização do sistema visual.

## Objetivo

Criar um **guia visual simples e organizado**, facilitando a padronização de cores, tipografia e hierarquia de textos em futuras interfaces.
